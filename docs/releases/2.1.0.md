# Knowledge 2.1.0

New Ingest runs now default to schema8 / deferred / core / consolidated-v1 with workflow_revision=2, matching the current automatic workflow. Checkpoints and exact-version final approval remain required. Existing interactive/deferred runs keep their frozen policy; alternate profiles remain explicit.

Query adds approved DomainGroup discovery, related-page navigation and validated Raw source_clipping provenance. Wiki/Domain/Group navigation, full evidence reads and optional BM25/hybrid/fallback are documented together. Direct answer delivery is the default guidance; independent enhanced review is a trusted-host opt-in. The existing optional feedback interface records actual returned/use distinctions and routes only meaningful increments to the real owner.

This release is a portable adaptation of committed framework sources, not a copy of a working knowledge library. No private corpus, index, configurations, session bindings, run history or author service is included. Tools, Research, AWS and meta remain optional; installing does not run Ingest, create models, query paid services, approve content or deploy a site.

Upgrade: retain user data, local Git/history and frozen runs. Inspect the managed-file update preview; edited framework files must be reconciled explicitly. Use the AWS upgrade/rollback commands when installed through AWS, or compare this immutable module tag with your current standalone version. Keep the old module and recipient data as a recovery point. Do not rewrite older run manifests or approvals. Verify the inventory after updating.
